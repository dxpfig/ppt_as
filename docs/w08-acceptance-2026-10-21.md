- 浏览器与 LibreOffice 渲染可用。
- 运行数据隔离在 `runtime/w08-benchmark-20261021/`。

## 已完成优化

- 模板转换按 `sourceSha256 + importer version` 缓存；同一模板 ID 内容变化会重建。
- 视觉能力像素探测按 provider/model/endpoint 缓存。
- 模型出现 429/529 时进入指数退避，暂停页面队列中的新模型请求。
- 页面仅保留实际引用的 `customFonts`，未使用的远程字体不再阻塞原生导出。
- 原生适配器不支持的 `line.arrow` 装饰字段被确定性剥离，不改正文、数据或几何。
- 纯排版问题先执行确定性 autofit，再允许模型修复。
- 新增 `pnpm perf:compare`，按总耗时、阶段和里程碑 p95 阻止性能回退。

## 性能门禁

`pnpm perf:compare` 对历史基线和新样本比较，未发现 p95 回退：

- 总耗时 p95：约 2017 秒 → 417.438 秒。
- 页面阶段 p95：约 2492 秒 → 124.339 秒。
- 导出阶段 p95：约 264 秒 → 162.715 秒。
- 视觉阶段 p95：约 308 秒 → 232.221 秒。

样本规模和场景不同，以上数据用于回退门禁，不作为严格的同输入性能承诺。

## 剩余风险

因此：W08 的低风险性能优化、阶段观测、缓存、并发门禁和真实链路复测已完成；长文档最终成功交付仍依赖视觉模型稳定返回完整审稿结果。
