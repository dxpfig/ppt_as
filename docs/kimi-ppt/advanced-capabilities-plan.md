# PPTD 高级能力实现计划

日期：2026-10-09。用户明确要求补齐公式、图标、动画、复杂图表和字体嵌入，授权在已有 PPTD 链路上实施。PPTD v2 继续作为唯一权威文档；Kimi 私有引擎不可取得。

## 范围和验收

本次新增可复用的浏览器运行模块 `packages/pptd-runtime/` 和 Python 格式适配模块 `pptd_engine/`，由已有 PPTD 加载、保存、预览和导出入口调用。既有 Agent 的主题/大纲工作流迁移不属于这五项能力的补齐范围。

所有能力同时检查：原始语义不丢失、浏览器呈现/交互、PPTX 对象/关系/资源与实际转换。禁止用保留字段冒充动画播放，用公式源码冒充公式，用整页图片冒充可编辑对象。规范未限定全部 TeX 扩展语法；非法或不能转换的公式必须定位报错。图表在 PowerPoint 缺少同类对象时，采用何种可编辑出口单独记录，不静默改变图类。

| 模块 | 输入和输出 | 验收重点 |
|---|---|---|
| 公式与图标 | PPTD 富文本 / iconName → 浏览器公式/SVG；PPTX 原生数学和矢量路径 | 行内、独立公式、表格公式、分数/根式/上下标/矩阵/积分；Font Awesome 7 Free 三种前缀与真实名称；缺失资源不得静默跳过。 |
| 动画 | Page.animations + 稳定元素 ID → 浏览器播放器与 PPTX 时间树 | 22 效果、onClick/withPrevious/afterPrevious、首组自动播放、delay/duration/easing/repeat、颜色/透明度/路径；重播和取消不污染文档。 |
| 图表 | Chart 的 data/encode/series/defaults/axes → 浏览器图表与原生/矢量出口 | 13 类、合法混合、双轴、堆叠、缺值、过滤、OHLC/HLC、瀑布总计、树和 DAG 校验；源数据可恢复。 |
| 字体 | customFonts 与实际使用字体 → 缓存的同一资源、浏览器加载、PPTX 嵌入 | 字体家族与样式识别、Google CSS/CDN、字符覆盖、字体嵌入许可位、真实格式和包关系；不把字体名或无效二进制当嵌入成功。 |
| 集成 | 所有模块 → 现有 PPTD 编辑/预览/导出链路 | 保留源文档和其他字段；错误定位到页面/元素/属性；不向 PPTD 添加未定义 App 字段。 |

## 必须覆盖的易错情况

- 公式中混合普通文字、中文、链接和主题样式；公式只能继承颜色与字号。
- 动画一页多组、同一元素多效果、第一项 withPrevious、进入/退出方向、持续效果和重复后的终态。
- 图表空值、字符串数字、非法 encode、错误类型混合、循环树/DAG、负 bubble size、瀑布不匹配总计。
- 字体 URL 不可用、字重与家族名称不匹配、缺字、禁止嵌入，以及浏览器可用但 Office 未安装字体。
- 编辑任何一个高级元素后，未编辑的主题、数据、动画、资源路径仍按 PPTD 原语义保存。
