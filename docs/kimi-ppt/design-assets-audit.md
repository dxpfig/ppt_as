# Kimi 设计资源核查与本轮界面修订

核查范围为本项目保存的 Kimi PPT skill 原始快照，不能据此推断 Kimi App 私有服务的全部资源。

## 原始 skill 是否带模板

`original/` 与 `manifest.json` 共记录 13 份 Markdown，校验值一致。没有附带 PPTX、PPTD、页面文件或图片模板包。

| 实际提供的内容 | 性质及出处 |
| --- | --- |
| 7 类场景指南 | 分析决策、商业提案、管理汇报、学术研究、教育培训、技术工程、品牌创意；见 `original/reference/slides_categories.md` |
| 4 种设计方式 | 自主设计、设计系统、用户模板、风格迁移；见 `original/SKILL.md` 第 28 行起 |
| 配色、字体、构图样例 | 场景指南中的文字设计配方；品牌指南第 31 行明确不将参考当作直接可用模板，技术指南第 172 行也禁止整套照搬 |
| 字体及图形目录 | 系统与 CDN 字体名称、URL 规则、形状参数、图标规范；不是预制整页文件 |
| 用户模板流程 | 读取用户提供的 PPTX、转换、截图、抽取组件与版式；见 `original/SKILL.md` 第 72 行起 |

因此，“复制了全部取得的规则文档”与“获得 Kimi App 的模型、排版引擎及私有资源”是两个不同的完成条件。后者目前没有取得，也不能确认 App 是否另有模板库。

## 已确认的视觉流程差距

1. 本地使用当前配置的 MiniMax-M3 执行规则，并非 Kimi 的模型及私有编排。
2. `auto` 场景的首次规划载入核心文件和场景索引；确定场景之后，逐页生成才载入对应详细指南。因此第一次全局主题规划尚未使用所选场景的完整风格建议。
3. 当前自动修复侧重结构、字体、裁切和原生导出兼容。尚未把整套渲染缩略图交给视觉模型审查构图、视觉节奏及全稿一致性。
4. 本地适配层限制部分渐变、阴影、字距和富文本效果；素材检索与原文强调的素材优先设计也存在流程差异。

这些是源代码可确认的差距，不能由“缺少模板”单独解释。本轮仅核查并记录这些流程差距，没有擅自引入模板服务或追加模型审稿调用。

- 预览左侧竖向缩略图列表，支持点击和滚轮切页；手势节流避免触控板惯性连续翻页。
