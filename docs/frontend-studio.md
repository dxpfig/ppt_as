# 叙页 Studio：前端工作台与原型记录

> **文档状态：已接入真实后端与 Agent。** 本页下半部分是历史原型记录，不再作为当前功能和运行方式的依据。最新架构、启动命令、模型配置、模板边界与集成验证见 [后端与 Agent 文档](backend-agent.md)。

## 当前工作台

- 桌面布局保留左侧对话 60%、右侧工作台 40%，展开后为 1:1；窄屏上下排列。
- 对话通过真实任务接口生成大纲、细化整份大纲或修改当前页。生成关键节点每秒轮询，不再模拟逐字输出或使用计时器伪造进度；支持取消、错误提示及刷新后继续查询任务。
- 支持从零生成，也可从附件或右侧模板区域上传、选择及移除公司 PPTX / POTX 模板。选中公司模板后禁用内置配色，避免误认为内置主题会覆盖品牌样式。
- 预览和播放使用实际 PPTX 经 PDF 渲染得到的 PNG，保留模板原始宽高比。可下载可编辑 PPTX、PDF 和 JSON 内容备份；渲染服务不可用时提示原因，不将 HTML 草稿当作公司模板的生成结果。
- 标题、正文、备注、页面顺序和主题等修改会使旧预览与下载失效。点击“应用修改并更新预览”生成新的文件。大纲草稿与正式预览分别标识。
- 项目自动保存至服务器，同时保留浏览器草稿；启动时读取服务器项目，存在不同的本机草稿时提供恢复入口。支持项目列表和版本恢复，版本包含项目标题、页面内容、主题、公司模板与对应产物。

## 当前仍存在的限制

- 编辑器支持结构化内容和页序编辑，尚未支持自由拖拽、任意元素定位、图片替换、图表数据编辑及完整 PowerPoint 排版能力。
- 公司模板沿用现有设计并填入内容，不保证任意复杂模板都能自动重排。图片中的文字、SmartArt、图表和动画的处理边界以 [模板生成边界](backend-agent.md#模板生成边界) 为准。
- 模型回复完成后显示结果；当前只有任务状态轮询，没有逐 token 流式回复。
- 修改后需要重新渲染才能获得最新正式预览；内容较多时应检查实际版式及是否溢出。
- TXT / Markdown / CSV / JSON / DOCX 参考资料和 PPTX / POTX 模板是目前的附件范围；DOCX 单文件默认最高 50 MB，通过 Mammoth 在浏览器内抽取正文，解析后文本按当前模型上下文动态限制。JSON 备份暂未提供导入入口。解析引擎选型见 [DOCX 解析引擎评估](docx-parser-selection.md)。
- 解析成功的参考资料会立即持久化到项目，并以独立文件卡显示 WORD/TEXT 类型、文件名、字数与“已添加”状态；可查看解析正文，也可下载服务端保留的原始文件。
- 项目和模板由当前服务器实例共享；尚未提供账号隔离、协作权限或多人同时编辑的冲突处理。自动事实核验、资料引用管理及费用预估也尚未实现。

## 历史原型记录

以下保留最初前端原型阶段的范围、交互说明与验证记录；其中“模拟”“仅本地”“未实现后端”等描述只适用于当时版本，不代表当前实现。

### 访问与运行

- `/` 与 `/studio` 展示工作台，无需先配置 AgentScope 服务。
- 既有 `/chat`、`/setup` 等路由保留原有流程。
- 启动：`pnpm --filter frontend dev --host 0.0.0.0 --port 5174`。
- 本轮局域网预览地址：`http://192.168.0.10:5174/`。
- 手机和窄屏采用上下布局；桌面默认左侧对话 60%、右侧工作台 40%（3:2），右栏最小 300px；展开编辑时调整为 1:1。

### 页面与交互

1. 左侧对话：用户气泡、助手回复、模拟逐字输出、停止、复制、重新回复、Enter 发送、Shift+Enter 换行、中文输入法兼容、自动跟随最新消息及返回底部。
2. 大纲确认：先展示章节，点击章节打开右侧编辑，确认后开始生成。页数与场景偏好应用到下次新主题请求。
3. 生成状态：理解需求、构建大纲、设计页面、完成演示。可停止，完成后显示幻灯片缩略图。
4. 预览和播放：16:9 画布、逐页浏览、放大、大屏播放、方向键翻页、Esc 退出、4.5 秒自动翻页。
5. 编辑：标题、副标题、要点、演讲备注、前移/后移、复制、删除、新增、撤销；三种配色实时应用。
6. 恢复能力：自动保存到 localStorage；最近 12 个生成/手动版本；刷新恢复；生成中刷新回到可确认大纲状态。
7. 参考材料：最多 5 个 TXT/Markdown 文件，每个不超过 1 MB；文字放入封面备注作参考，不上传、不执行模型解析。
8. 导出：HTML 离线阅读稿（简化版式，可由浏览器打印为 PDF）、JSON 内容备份。PPTX/原版式 PDF 未实现，并在界面说明。
9. 本地新建操作会先提示备份，防止误清空当前作品。

### 原型阶段边界

- 默认展示一份 AI 工作方式的六页示例，方便完整体验。
- 新主题采用本地模板，生成进度使用计时器，不代表真实大模型能力。
- 已生成演示的自然语言修改仅演示回复和定位编辑区；实际更改通过右侧编辑表单完成。
- 这是结构化内容编辑器，不是自由拖拽画布；长文本可能在画布预览中截断，编辑字段中保留内容。
- 各浏览器数据独立，不做账号、多端同步和协同编辑。
- JSON 为可读备份，当前未提供导入入口。
- 附件不会传至服务端，真实文件解析和上传留待后端阶段。

### 当时计划的推进顺序

1. 用户确认布局、视觉风格和核心交互。
2. 设计后端架构与接口：项目/版本持久化、文件存储、生成任务、SSE 状态、失败重试、取消与导出。
3. 再讨论 PPT Agent 的职责与组件选型：规划、检索、页面结构、渲染、质量检查和导出。
4. 若后续使用 Python，在项目内建立 `.venv` 并通过该环境运行与安装依赖，禁止使用系统全局 Python 环境。

- 前端 TypeScript 检查与生产构建通过；构建仍提示既有依赖体积较大及 mime-types 的浏览器兼容警告。
- 新增页面与修改入口的 ESLint、Prettier 检查通过。
- 浏览器验证：大纲确认、生成完成、停止生成、展开编辑、标题实时预览、撤销、键盘翻页、版本恢复、主题切换、刷新恢复。

## 工作记录与首次进入

- 首次进入是零消息、零幻灯片的欢迎页。只有实际输入需求、命名项目或上传模板后才创建服务器记录，空白首页不产生无意义的历史项目。
- 最左侧「工作记录」展示项目名称、页数及最近更新时间，可收起。点击记录前会完成当前内容的保存；切回后恢复对话、页面、讲稿、版本、模板、配色、页数、使用场景及已提交的参考材料。
- 输入框中未发送的文字、未提交的附件及撤销栈不会带到另一份演示。生成、上传和保存切换期间暂时禁用记录切换，生成可先停止再切换。
- 删除有确认提示，删除后可点击左栏「撤销删除」。删除当前记录会返回空白创作页；删除其他记录不影响当前编辑。
- 首次升级到 v3 会清除原型 v1/v2 的浏览器缓存及旧测试任务引用，后续刷新正常保留新工作。2026-09-30 的演示和验收数据已移出活动库，可恢复备份位于 `runtime/backups/before-clean-start-20260930-142236/`。
